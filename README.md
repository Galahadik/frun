# FRun (Fabric 26.3)

Сборка: `./gradlew build` -> `build/libs/frun-1.0.0.jar` (Java 25).
Впишите версию Fabric API для 26.3 в gradle.properties (https://fabricmc.net/develop).

## Разовая настройка базы лобби (бесплатно, 3 минуты, делает один человек)
1. https://console.firebase.google.com -> Add project (аналитику можно выключить).
2. Build -> Realtime Database -> Create database (любой регион, режим «locked»).
3. Вкладка Rules, вставьте и Publish:
   {
     "rules": { "friendrun": { ".read": true, ".write": true } }
   }
4. Скопируйте URL базы (вида https://xxxx-default-rtdb.firebaseio.com) и разошлите друзьям.
   Каждый вставляет его один раз в поле «URL базы Firebase» в меню мода (сохранится в config/friendrun.json).
Внимание: любой, кто знает URL, может писать в /friendrun — используйте только с друзьями.

## Как играть
1. Главное меню -> кнопка FRun (слева сверху).
2. Хост вводит название -> «Создать». У друзей это лобби появляется в списке «Открытые лобби» — нажать на него, чтобы войти.
3. В комнате хост выбирает режим и роллит предмет:
   - отдельные миры: у каждого свой мир, но один seed;
   - мир хоста: хост создаёт мир, e4mc даёт ему домен, домен автоматически уходит в лобби,
     остальные заходят сами. Нужен мод e4mc у хоста (у остальных — не нужен).
4. Хост жмёт «Старт» -> создаются миры.
5. В мире все пишут /go. Когда готовы все — отсчёт 5 сек и старт. Первый с предметом в инвентаре побеждает
   (при одновременном — у кого меньше время). Потом предмет роллится заново, снова /go.

Команды: /go, /rr leave, /rr status.
Часы на компьютерах должны быть синхронизированы (по умолчанию Windows/macOS это делают) — по ним идёт общий отсчёт.
У всех должны совпадать версия игры и моды.

## Настройки мода
Открываются: главное меню -> FRun -> строка **«Настройки мода»**, а в комнате лобби — кнопка **«Настройки»** в шапке.
Сохраняются в `config/friendrun.json`.

Вкладки:
- **Предметы** — все предметы, которые могут выпасть, с иконками. Клик по строке включает/выключает предмет.
  Есть поиск (по названию и id), фильтр «все / включённые / выключенные» и кнопки «Включить/Выключить найденные»
  (например, найти «шаблон» или «пластинка» и выключить всё разом). Колесо мыши или стрелки справа — прокрутка.
- **Усложнения** — все усложнения с описанием; любое можно выключить. Рулетка усложнения крутится только по включённым.
  Если выключены все, случайное усложнение в лобби включить нельзя.
- **Прочее**
  - для всего лобби: «исключить очень тяжёлые предметы» (незерит, элитры, маяк, диски, шаблоны…);
    «равный шанс у каждого предмета» (иначе шанс по семействам: все цвета шерсти считаются одним вариантом);
  - только у вас: усложнение включено в новых лобби, звуки рулетки, сброс всех настроек.

Как это работает в лобби: **настройки хоста передаются всем игрокам** (предмет вычисляется у каждого из seed, поэтому пул
обязан совпадать). Хост меняет пул предметов до нажатия «Старт» (после старта предметы заморожены); усложнения — в любой момент.
Остальные игроки в лобби видят настройки хоста в режиме просмотра. Если выключить все предметы, используется полный список.
При смене пула предмет перебрасывается автоматически, чтобы выпавший был из нового набора.
Вне лобби настройки просто сохраняются и применяются к лобби, которые вы создаёте.

## Рейтинг (MMR) и таблица лидеров
У каждого игрока **общий рейтинг** (меняется от любого рейтингового раунда) и **отдельный рейтинг в каждом режиме**
(спидран, конвейер, цепочка, бинго, волны, манхант, столбы). Рейтинг идёт только в лобби **от 2 игроков**. Старт — 1000.

Как считается (Elo, считает хост в конце раунда):
- **Спидран, цепочка, бинго** — победитель (первый закончивший) против всех остальных.
- **Конвейер, волны** — места по очкам (конвейер: при равенстве выше тот, кто набрал раньше; волны: кто дольше продержался).
  Каждая пара «выше/ниже» даёт очки, поэтому второй и третий места тоже что-то значат. Полная ничья рейтинг не меняет.
- **Столбы** — победитель раунда карты (один игрок или команда) против всех остальных игроков лобби. «Никто не победил!» рейтинг не меняет.
- **Манхант** — команды: считается средний рейтинг беглецов и охотников, очки делятся с поправкой на размер команд.
- Вес раунда одинаков для лобби из 2 и из 6 человек (победа над равным ≈ +16). Победить сильного выгоднее, чем слабого.
  Первые 5 игр **в каждом режиме** — калибровка (изменения ×1.5), чтобы новички быстрее находили свой уровень.
  Рейтинг не опускается ниже 0.
- Ранги: Дерево (<800), Камень (<1000), Железо (<1200), Золото (<1400), Алмаз (<1600), Незерит (1600+).
  О смене ранга пишется в чат.

Где смотреть:
- Главное меню -> FRun -> **«Таблица лидеров»**, кнопка **«Топ»** в комнате лобби, команды `/rr top` (общий) и
  `/rr top speedrun|conveyor|chain|bingo|waves|manhunt|pillars` (по режиму).
- В таблице вкладки «Общий» и по каждому режиму: место, игрок, ранг, MMR, победы/игры, а последняя колонка зависит от режима
  (лучшее время, рекорд очков или винрейт). Ваша строка закреплена внизу. Таблица открывается на вкладке текущего режима лобби.
- После раунда: в чате и на панели итога видно изменение рейтинга в режиме и общего.
- В комнате лобби рядом с именами игроков показан их рейтинг **в выбранном режиме**.

Технически:
- Данные лежат в той же Firebase: `friendrun/_mmr/<ник>` = общий рейтинг + `modes`. Менять правила базы не нужно.
  Записи первой версии (рейтинг только за спидран) подхватываются автоматически: их значение становится рейтингом в спидране.
- Ник — это ник Minecraft-аккаунта. Названия лобби не могут начинаться с `_` (служебные узлы).
- Рейтинг считает хост, а база открыта, поэтому система работает на доверии: тот, кто знает адрес базы, технически может
  править таблицу. Для друзей этого достаточно; для публичной игры понадобились бы авторизация и сервер.

## Сборка на GitHub (без установки Java)
Залейте проект в репозиторий -> вкладка Actions -> Build mod -> когда закончится, внизу Artifacts -> friendrun-mod (это jar).
Не забудьте вписать fabric_version в gradle.properties.

### Режим «Столбы»

В проект встроена готовая карта «Столбики» из архива `pillarsOfFortune.zip`. Выберите режим «Столбы» и нажмите «Старт»: хост распакует копию карты в `saves/FRun-…` и откроет её. Для совместной игры автоматически выбирается общий мир хоста; остальные игроки подключаются к нему штатным способом FriendRun. Правила самой мини-игры остаются внутри карты — FriendRun не добавляет отдельную механику для этого режима.

Рейтинг в «Столбах»: раундами и победителем управляет сама карта, поэтому FriendRun узнаёт итог по её сообщению в чате
(«<ник> победил(а)!», «<Цвет> команда победила!», «Никто не победил!»). Это делает **хост лобби** (у него общий мир):
он считает MMR и пишет его в ту же таблицу `friendrun/_mmr`. `/go` в этом режиме не нужен. Рейтинг идёт только при
2+ игроках в лобби; проигравшими считаются все остальные игроки лобби, даже если кто-то из них только наблюдал.
